Z. That is the whole entry: exactly one letter, standing for the word that describes the day — "zombie". After a night of nonstop work with zero sleep, the day is a zombie day: shambling, half-awake, and still going. Z is the sharpest initial for it, an uncommon letter carrying an unmistakable picture, funny because it is true. This program writes the letter to `/output/entry.txt` for the judge, after checking it is exactly one letter from A to Z.

## Run

```sh
python3 main.py
```
